# Agent 辅助阅读器 · UI/UX 方案（交互层）

> 版本：v1 | 日期：2026-09-01 | 状态：已定稿 | 评审轮次：4 轮
> 人读版（评审草图）：.doc-visualizer-output/2026-09-01_阅读器UIUX三方案.html
> 上游文档：《2026-08-31_agent辅助阅读器.md》（架构，已定稿）。本文档是其**交互层**的展开：只定义读者可见可操作的界面，不改变上游架构分层、红线与里程碑定义。

## 1. 目标与范围

**目标**：为 Agent 辅助阅读器定义完整的交互层设计——阅读页布局、涂写提问动线、AI 回答呈现（页边便签）、图解呈现（小卡 + 剧场）、对话抽屉、导航与费用可见性。最终方向（第 2 轮拍板）：**混搭 = 方案 A 纸感书桌为底 + 方案 C 的剧场放大 + 方案 B 的对话流收进"默认关闭的浮层对话抽屉"**。

**范围**：

- 产品形态：纯网页应用（上游 D1）；桌面浏览器，主力目标 27 寸外接屏（本文 Q1）；兼容 ≥1024px 视口（降级规则见 3.2.5）
- 输入设备：第一版以鼠标 / 触摸板为目标（上游 R4）
- 书型：经济学类书籍；书籍来源为用户自行上传（上游 Q4）
- 覆盖界面：顶部工具条、中央书页、页边便签区、涂写层与模式开关、AI 便签卡、图解小卡与剧场模式、对话抽屉、目录拉手与全书地图、费用显示、章末问答清单

**非目标**（后置，不在本版）：

- 移动端 / 平板专属布局
- 手写笔压感与防误触优化（上游 R4 列二期）
- 多书库管理界面（上游不建书库）
- 账号、计费界面（上游后置）

## 2. 总体设计

### 2.1 交互层与架构四层的对应

本文档只展开上游架构的**交互层**；Agent 层、生成层、书籍层接口不变。交互层消费的上游接口：

| 上游模块 | 交互层消费的数据/能力 |
|---|---|
| 书籍解析（上游 3.1） | BookDoc：`toc[]`、章节段落、稳定 `paraId`（章节序+段序）、`figures[]` |
| 上下文管理（上游 3.2） | 当前章节装载状态、全书目录地图、旁证检索触发 |
| 问答与引用（上游 3.3） | 回答文本 + `{paraId, quote}[]` 引用列表 |
| 图解生成（上游 3.4） | 沙箱渲染的自包含 HTML/SVG/JS 组件、失败降级态、缓存命中标记 |
| 涂写意图（上游 3.5） | 区域截图 + 笔迹 + 可选附言的提交通道 |
| 成本闸门（上游 3.6） | 累计费用、缓存命中数、频率限制状态 |

### 2.2 四种使用状态

| 状态 | 场景占比（Q2） | 进入方式 | 屏幕布局 |
|---|---|---|---|
| 通读态（默认） | 50% | 打开书即是（D2） | 书页完整 + 页边便签；对话抽屉关闭；模式 = 阅读 |
| 圈选态 | 40% | A 键 / 顶栏开关 | 鼠标变笔；画圈 → 附言气泡 → 便签钉页边 |
| 深聊态 | — | 顶栏 💬 / 便签"展开深聊" / D 键 | 浮层对话抽屉从右缘滑出（D4），不挤压书页 |
| 跳读态 | 10% | 左缘"目录"拉手 / 抽屉头部"全书地图" | 章节树 / 全书目录地图浮出，点章节直接跳 |

## 3. 详细设计

### 3.1 阅读页布局（方案 A 底座）

- **三区结构**：顶部工具条（高 40px）+ 中央书页 + 左右页边便签区；书页左缘有竖排"目录"拉手。
- **顶部工具条**（左 → 右）：书名 · 当前章节标题｜中央"阅读 / 圈选"分段开关（默认"阅读"，D2）｜右侧："💬 对话"按钮（呼出抽屉）、累计费用（如 `¥0.42 · 本会话`）。
- **书页**：居中，最大宽度约 46rem，背景纯白；页面底色纸感 `#faf9f6`；正文衬线字体栈 `"Noto Serif SC","Songti SC","SimSun",Georgia,serif`；书页两侧留白即页边便签区（各约 15rem，27 寸下可并排 2~3 张便签）。
- **段落锚点**：便签 / 图解 / 引用跳转全部使用上游 BookDoc 的稳定 `paraId` 挂载，不引入新的锚点体系。
- **目录拉手**：常驻左缘（竖排文字"目录 ⟨"），hover / 点击从左缘滑出章节树（数据 `toc[]`），点击章节跳转。
- **全书地图**：入口在对话抽屉头部（3.5）与目录面板顶部，展示上游 3.2 构建的全书目录地图，点击任意章节跳转；跨章提问由上游自动触发旁证检索，交互层无需单独入口。

### 3.2 涂写交互（上游 3.5 的界面化）

- **3.2.1 模式开关**：默认"阅读"（D2，第 2 轮）。切换 = 顶栏分段开关或快捷键 `A`。阅读模式下已画笔迹与便签照常显示，仅禁用新绘制；阅读模式下鼠标拖拽保持 EPUB.js / PDF.js 原生行为（选中文本、翻页）。
- **3.2.2 圈选**：圈选模式下鼠标按住拖拽即画圈（透明 Canvas 覆盖层，笔迹红色 `#ef4444`）；松开鼠标即完成一次圈选。
- **3.2.3 附言气泡**：圈选完成后在圈旁弹出单行输入气泡：留空直接发送，或补一句话（上游 D4"圈选截图 + 笔迹提示"）；`Esc` 或点击圈外取消。
- **3.2.4 合成与提交**：截取该区域书页 + 笔迹的合成图，连同附言走上游 3.5 视觉模型意图解析。提交后便签立即以"生成中"占位态钉出（乐观呈现），无需等待。
- **3.2.5 窄屏降级**：视口 < 1024px 时页边便签区收起，便签按时间序堆叠在书页底部（固定高度可滚动区）；< 768px 不在本版支持范围。

### 3.3 AI 便签卡（回答的页内呈现，上游 D5"页内为主"）

- **位置**：钉在页边便签区，垂直位置对齐所圈段落的 `paraId` 对应 DOM 高度；同屏多张按高度排布，重叠时纵向错位 8px。
- **结构**（自上而下）：
  1. 标题行：📌 + `图解 · <概念名>` 或 `讲解 · <问题摘要>`
  2. 内容区：图解小卡（内嵌沙箱动画组件，自动演示）+ 文字讲解（**默认折叠**，可展开）
  3. 标注行：**"辅助理解，以原文为准"**（必带，上游红线 2）
  4. 操作行：`⤢ 剧场放大`（见 3.4）｜`↗ 原文 <paraId>`｜`展开深聊`（见 3.5）
- **引用回跳**：回答携带的全部 `{paraId, quote}[]` 渲染为引用 chips；点击任意 chip → 书页滚动到对应段落并高亮闪烁 2 秒（上游红线 2 的执行载体）。
- **状态机**：生成中（骨架 + 转圈）→ 已呈现（小卡 + 折叠讲解）→ 降级（上游重试 1 次仍失败：静态图 + 文字讲解，标注不变）。
- **便签管理**：便签可关闭（仅移除显示，缓存不清，同概念再次提问命中上游缓存直接呈现）；章末提供"本章问答清单"入口，列出本章全部便签并可点击定位。

### 3.4 图解剧场模式（借方案 C；D3 定案）

- **触发**：便签卡或抽屉内图解小卡的 `⤢` 按钮。
- **形态**：全屏模态，深色画布（`slate-900` 底），图解组件以最大尺寸居中渲染——**同一沙箱组件换容器渲染，不重新生成**（缓存不命中新键）。
- **底栏**（必含）：一句话结论（如"供给左移 → 均衡价 P₀ 升至 P₁"）+ "辅助理解，以原文为准"标注 + `↗ 回到原文 <paraId>` + `继续追问`（打开对话抽屉）+ `✕`。
- **关闭**：`✕` / `Esc`；回到触发点原位，图解缓存态不变。
- **配色约束**：剧场为深色是定案。图解组件必须同时适配浅色小卡与深色剧场两种容器——上游生成提示词要求组件背景透明、文字/线条用 `currentColor`。

### 3.5 对话抽屉（收方案 B；D4 定案：浮层抽屉）

- **形态**：浮层面板从右缘滑出，宽度 `min(420px, 40vw)`，**覆盖在书页之上（overlay），不挤压、不重排书页**，带投影与左边框。
- **默认状态**：关闭（D1 备注，第 2 轮）；任何状态下不得自动弹出。
- **呼出入口（三个）**：① 顶栏"💬 对话"按钮；② 便签卡"展开深聊"（携带该便签的问答对作为局部上下文）；③ 快捷键 `D`。关闭：`✕` / `Esc` / 再按 `D`。
- **内容结构（三段）**：
  1. 头部：`对话 · 接着<章节/便签>聊` + `全书地图`入口 + `✕`
  2. 对话流：完整消息历史。用户消息含圈选截图缩略图与附言；AI 消息含文字、引用 chips、内嵌图解小卡、"以原文为准"标注。默认自动滚动到底，用户上滚即停止跟随。
  3. 输入行：`✏️` 按钮（点按切到圈选态）+ 单行文本框（placeholder：`补一句话（可不填，直接圈选也行）`）+ 发送。**打字仅为补充入口，涂写仍是第一提问入口**（UI 硬性要求 1）。
- **上下文**：继承上游混合式上下文（全书摘要常驻 + 当前章装载 + 旁证检索）；从便签进入时附加该便签问答对。
- **抽屉内引用点击**：抽屉暂收起 → 书页跳转并高亮 → 上下文保留，可再次呼出继续。

### 3.6 费用与限流呈现（上游 3.6 / 红线 3）

- 顶栏常驻累计费用（本会话），hover 显示明细（生成次数、缓存命中数）；对话抽屉打开时头部同步显示同一数据。
- 达到会话生成频率限制的 80% 时费用文字变琥珀色；触发限制时便签占位态显示"已达频率上限，稍后自动重试"——**不允许静默失败**。

### 3.7 快捷键

| 键 | 动作 |
|---|---|
| `A` | 阅读 ↔ 圈选模式切换（D2） |
| `D` | 对话抽屉开 / 关（D4） |
| `Esc` | 关闭最上层浮层（附言气泡 / 对话抽屉 / 剧场 / 目录） |
| `←/→`、`PgUp/PgDn` | 翻页（沿用 EPUB.js / PDF.js 默认） |

快捷键在文本输入框聚焦时一律失效；每个快捷键都有顶栏等价按钮。

### 3.8 视觉与主题

- **常态浅色纸感**：书页纯白、页面底 `#faf9f6`、便签琥珀系（底 `amber-50`、边 `amber-300`）、圈选笔迹 `#ef4444`、主操作/模式开关紫 `purple-600`、对话元素蓝 `blue-600`、剧场/成功态绿 `emerald-600`。
- **剧场深色**：`slate-900` 画布、`slate-800` 底栏；图解组件双向适配（3.4 配色约束）。
- **字体**：正文衬线栈（3.1）；工具条、便签操作行、抽屉等 UI 控件用无衬线默认栈。

## 5. 约束与红线

上游 3 条红线（内容不外流、讲解锚定原文、成本闸门）全部继承；交互层具体化为：

1. **不允许出现无引用的回答卡片**：便签、抽屉消息、剧场内的每个回答必须带可点击引用 chips，点击必须跳转书页并高亮（红线 2）。
2. **"辅助理解，以原文为准"标注必带**：图解小卡与剧场底栏都必须渲染；讲解文字默认折叠（红线 2）。
3. **费用常驻可见，限流必须显式反馈**：任何生成入口触发频率限制时呈现明确文案，禁止静默失败（红线 3）。
4. **对话抽屉必须保持"默认关闭 + 手动呼出"**（D1 备注 / D4），不得改为常驻分栏或自动弹出。
5. **书页布局在任何浮层状态下不得重排**（D4 浮层定案）；剧场模式的全屏覆盖是唯一例外——它是用户主动触发的模态。

## 6. 验收标准

- **U1**：2560×1440 浏览器最大化下书页 + 双页边便签区完整呈现，书页无横向滚动；视口 1024px 时便签退化为书页底部堆叠且不遮挡正文。
- **U2**：纯鼠标完成"切圈选 → 画圈 → 留空发送"全程 ≤ 3 次点击 + 1 次拖拽；阅读模式下画笔无效且不误触翻页；按 `A` 后 200ms 内模式生效。
- **U3**：任一便签 `↗ 原文` 点击后书页滚动定位到对应段落并高亮闪烁 2s，以 paraId 为准定位准确率 100%；"以原文为准"标注在便签与剧场 100% 出现。
- **U4**：同一图解组件在小卡与剧场两种容器渲染一致（无布局崩坏、文字可读）；剧场开/关不产生新的生成调用（缓存命中）。
- **U5**：抽屉打开/关闭前后书页滚动位置与布局零变化；从便签进入抽屉后的首轮回答能正确引用该便签上下文（人工判定通过）。
- **U6**：顶栏费用与上游成本闸门数据一致；达 80% 阈值变琥珀色；触发限流时便签出现明确文案。
- **通用**：EPUB 与文字版 PDF 两种格式下以上各项均成立；浏览器控制台 0 错误；快捷键在输入框聚焦时不触发。

## 7. 已确认的决策记录

| 编号 | 决策点 | 定案 | 理由 | 轮次 |
|---|---|---|---|---|
| D1 | 整体方向 | **混搭**：以方案 A 为底 + 借方案 C 的剧场放大 + 支持常用对话交互，但对话栏默认关闭、手动触发打开 | 用户拍板（备注原文）；B 常驻分栏压窄书页、形态最像对话框；C 就地浮卡回溯弱。两者的优点分别以"对话抽屉"和"剧场放大"保留 | 第 2 轮 |
| D2 | 涂写模式默认态 | 默认"阅读"模式，点开关或按 `A` 进入圈选 | 不会误画、翻页永远顺畅；已画笔迹与便签在阅读态保留显示 | 第 2 轮 |

## 8. 风险与开放问题

| 编号 | 风险 | 规避措施 |
|---|---|---|
| U-R1 | 页边便签按段落高度定位，EPUB 与 PDF 渲染差异大，锚点高度可能漂移 | 用 paraId 对应 DOM 元素的实时位置计算（`getBoundingClientRect`），章节切换 / 字号调整 / 窗口缩放后重算；U3 验收含 100% 定位准确率 |
| U-R2 | 生成的图解组件在浅色小卡与深色剧场两种容器中适配不可控 | 上游生成提示词强制透明背景 + `currentColor`；U4 验收双容器检查；失败走上游降级链路（静态图 + 文字） |
| U-R3 | 浮层抽屉盖住书页右侧，读长讲解时需收起查看被遮内容 | 引用点击自动暂收抽屉；`Esc` 即收；宽度固定 `min(420px, 40vw)` 已为书页留出主体 |
| U-R4 | 快捷键与浏览器 / 输入法冲突 | 输入框聚焦时失效；每个快捷键均有顶栏等价按钮 |

**开放问题**：① 对话抽屉宽度是否支持拖拽调节（U5 实现时定，不影响红线）；② "本章问答清单"具体形态——章末浮层还是抽屉过滤视图（U3 实现时定，二者均满足 3.3 要求）。
