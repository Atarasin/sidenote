  • 鼠标 / 触摸板为第一版输入目标（上游 R4）

3.1 阅读页布局（方案 A 底座）

  • 三区结构：顶部工具条（高 40px）+ 中央书页 + 左右页边便签区；书页左缘竖排"目录"拉手。
  • 顶部工具条：书名 · 当前章节标题｜中央"阅读 / 圈选"分段开关（默认"阅读"，D2）｜右侧"💬 对话"按钮、累计费用（如 ¥0.42 · 本会话）。
  • 书页：居中，最大宽度约 46rem，背景纯白；页面底色 #faf9f6；正文衬线字体栈 "Noto Serif SC","Songti SC","SimSun",Georgia,serif；页边便签区各约 15rem，27 寸下可并排 2~3 张便签。
  • 段落锚点：便签 / 图解 / 引用跳转全部使用上游 BookDoc 的稳定 paraId 挂载，不引入新锚点体系。
  • 目录拉手：常驻左缘，hover / 点击滑出章节树（数据 toc[]），点章节跳转。
  • 全书地图：入口在抽屉头部与目录面板顶部，展示上游 3.2 的全书目录地图；跨章提问由上游自动触发旁证检索。

3.2 涂写交互（上游 3.5 的界面化）

3.2.1 模式开关

默认"阅读"（D2）。切换 = 顶栏分段开关或快捷键 A。阅读模式下笔迹与便签照常显示、仅禁用新绘制；拖拽保持 EPUB.js / PDF.js 原生行为。

3.2.2 圈选

圈选模式下按住拖拽即画圈（透明 Canvas 覆盖层，笔迹红 #ef4444）；松开鼠标即完成。

3.2.3 附言气泡

圈旁弹出单行输入气泡：留空直发或补一句话（上游 D4）；Esc 或点圈外取消。

3.2.4 合成与提交

区域截图（书页 + 笔迹）+ 附言走上游 3.5 视觉模型解析；便签立即以"生成中"占位态钉出（乐观呈现）。

3.2.5 窄屏降级

视口 < 1024px：页边便签区收起，便签按时间序堆叠在书页底部（固定高度可滚动）；< 768px 不在本版支持范围。

3.3 AI 便签卡（回答的页内呈现，上游 D5"页内为主"）

  • 位置：钉在页边便签区，垂直对齐所圈段落的 paraId 对应 DOM 高度；同屏多张重叠时纵向错位 8px。
  • 结构：标题行（📌 图解 · 概念名 / 讲解 · 问题摘要）→ 内容区（图解小卡自动演示 + 文字讲解默认折叠）→ 标注行（"辅助理解，以原文为准"必带）→ 操作行（⤢ 剧场放大｜↗ 原文 paraId｜展开深聊）。
  • 引用回跳：{paraId, quote}[] 全部渲染为引用 chips；点击 → 书页滚动到对应段落并高亮闪烁 2 秒（上游红线 2 执行载体）。
  • 状态机：生成中（骨架+转圈）→ 已呈现 → 降级（上游重试 1 次仍失败：静态图 + 文字讲解，标注不变）。
  • 管理：便签可关闭（仅移除显示，缓存不清，同概念再次提问命中上游缓存直接呈现）；章末"本章问答清单"可点击定位。

3.4 图解剧场模式（借方案 C；D3 定案）

剧场模式：图解的全屏大画布（深色），同一沙箱组件换容器渲染、不重新生成 ✕ / Esc 关闭
✕
供给左移 → 均衡价 P₀ 升至 P₁，可亲手拖动曲线 辅助理解，以原文为准 ↗ 回到原文 P3-12 继续追问
  • 触发：便签卡或抽屉内图解小卡的 ⤢ 按钮。
  • 形态：全屏模态，深色画布（slate-900），组件最大尺寸居中——同一沙箱组件换容器渲染，不重新生成（不命中新缓存键）。
  • 底栏必含：一句话结论 + "辅助理解，以原文为准" + ↗ 回到原文 paraId + 继续追问（打开抽屉）+ ✕。
  • 配色约束：组件必须同时适配浅色小卡与深色剧场——上游生成提示词要求背景透明、文字/线条用 currentColor。

3.5 对话抽屉（收方案 B；D4 定案：浮层抽屉）

  • 形态：浮层面板从右缘滑出，宽度 min(420px, 40vw)，覆盖在书页之上（overlay）、不挤压不重排，带投影与左边框。
  • 默认关闭（D1 备注）；任何状态下不得自动弹出。
  • 呼出（三入口）：顶栏"💬 对话"；便签"展开深聊"（携带该便签问答对为局部上下文）；快捷键 D。关闭：✕ / Esc / 再按 D。
  • 内容三段：头部（对话 · 接着<章节/便签>聊 + 全书地图入口 + ✕）｜对话流（用户消息含圈选截图缩略与附言；AI 消息含文字、引用 chips、内嵌图解、"以原文为准"；默认滚底，用户上滚停止跟随）｜输入行（✏️ 切圈选 + 文本框 + 发送——打字仅补充，涂写是第一入口）。
  • 上下文：继承上游混合式上下文（全书摘要常驻 + 当前章装载 + 旁证检索）。
  • 抽屉内引用点击：抽屉暂收 → 书页跳转高亮 → 上下文保留可再开。

3.6 费用与限流呈现

  • 顶栏常驻累计费用，hover 显示明细（生成次数、缓存命中数）；抽屉打开时头部同步
  • 达频率限制 80% 时费用文字变琥珀色
  • 触发限制时便签显示"已达频率上限，稍后自动重试"——不允许静默失败

3.7 快捷键

A阅读 ↔ 圈选切换（D2）
D对话抽屉开/关（D4）
Esc关闭最上层浮层
←/→翻页（沿用渲染器默认）

输入框聚焦时一律失效；每个快捷键均有顶栏等价按钮。

3.8 视觉与主题

  • 常态浅色纸感：书页白、页面底 #faf9f6、便签琥珀系、笔迹 #ef4444、主操作紫 purple-600、对话蓝 blue-600
  • 剧场深色：slate-900 画布、slate-800 底栏；组件双向适配
  • 正文衬线、UI 控件无衬线（3.1 字体栈）

上游 3 条红线（书籍内容不外流、AI 讲解锚定原文、成本闸门）全部继承；交互层具体化为以下 5 条：

红线 1 · 不允许出现无引用的回答卡片

便签、抽屉消息、剧场内的每个回答必须带可点击引用 chips，点击必须跳转书页并高亮（上游红线 2）。

红线 2 · "辅助理解，以原文为准"标注必带

图解小卡与剧场底栏都必须渲染；讲解文字默认折叠（上游红线 2）。

红线 3 · 费用常驻可见，限流必须显式反馈

任何生成入口触发频率限制时呈现明确文案，禁止静默失败（上游红线 3）。

红线 4 · 对话抽屉必须保持"默认关闭 + 手动呼出"

D1 备注 / D4 定案；不得改为常驻分栏或自动弹出。

红线 5 · 书页布局在任何浮层状态下不得重排

D4 浮层定案；剧场模式的全屏覆盖是唯一例外——它是用户主动触发的模态。

U1

2560×1440 浏览器最大化下书页 + 双页边便签区完整呈现，书页无横向滚动；视口 1024px 时便签退化为书页底部堆叠且不遮挡正文。

U2

纯鼠标完成"切圈选 → 画圈 → 留空发送"全程 ≤ 3 次点击 + 1 次拖拽；阅读模式下画笔无效且不误触翻页；按 A 后 200ms 内模式生效。

U3

任一便签 ↗ 原文点击后书页滚动定位到对应段落并高亮闪烁 2s，以 paraId 为准定位准确率 100%；"以原文为准"标注在便签与剧场 100% 出现。

U4

同一图解组件在小卡与剧场两种容器渲染一致（无布局崩坏、文字可读）；剧场开/关不产生新的生成调用（缓存命中）。

U5

抽屉打开/关闭前后书页滚动位置与布局零变化；从便签进入抽屉后的首轮回答能正确引用该便签上下文（人工判定通过）。

U6

顶栏费用与上游成本闸门数据一致；达 80% 阈值变琥珀色；触发限流时便签出现明确文案。

通用

EPUB 与文字版 PDF 两种格式下以上各项均成立；浏览器控制台 0 错误；快捷键在输入框聚焦时不触发。

D1整体方向已定 · 第 2 轮

混搭：以方案 A 为底 + 借方案 C 的剧场放大 + 支持常用对话交互，但对话栏默认关闭、手动触发打开。理由（用户拍板）：B 常驻分栏压窄书页、形态最像对话框；C 就地浮卡回溯弱——两者优点分别以"对话抽屉"和"剧场放大"保留。

D2涂写模式默认态已定 · 第 2 轮

默认"阅读"模式，点开关或按 A 进入圈选。理由：不会误画、翻页永远顺畅；已画笔迹与便签在阅读态保留显示。

D3图解默认呈现已定 · 第 2 轮

就近小卡内嵌自动演示 + ⤢ 一键剧场放大。理由：打断最小；大画布想要就有（剧场借自方案 C）。

D4对话抽屉形态已定 · 第 3 轮

浮层抽屉：盖在书页上、不挤压不重排，✕/Esc 收起。理由：书页布局永不变化，与"通读优先"（Q2 占比 50%）一致；固定分栏布局跳动；"浮层可钉住"实现量最大，留到真实使用确有长聊挂机需求再加。

Q1主力设备已回答 · 第 2 轮
